
flight Management System (BST)

Project Description
This is a C++ Flight Management System implemented using a Binary Search Tree (BST).

The system allows users to:
- Add new flights.
- Search flights by ID.
- Display flight records.
- Search flights by status.
- Calculate estimated arrival times (ETA).
- Save and load flight records using file handling.

 Technologies Used
- C++
- Binary Search Tree (BST)
- File Handling

 How to Run
1. Download or clone the repository.
2. Open main.cpp in Visual Studio or other C++ compiler.
3. Compile and run the program.
4. Make sure flights.txt is in the appropriate working directory if the program uses it.
